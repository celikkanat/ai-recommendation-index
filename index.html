    Method: 100 questions, 10 buyer profiles, ChatGPT and Gemini, web search on, same questions every week. When the measurement is repeated on the same day, brand rates move by ±2 points on average; week-to-week changes are treated as meaningful only when they are above that noise. As of week 4 we count the first three distinct brands in each answer; all previous weeks were recomputed with the same rule. Earlier published figures differ, in a few cases by more than 10 points. New categories (from October 14): 50 questions each, five buyer situations, every question asks for specific models. In travel bags and hair tools the product asked about changes with the buyer situation, so results there are shown per situation.
    Models: We use the API model closest to each app's free default. ChatGPT side: weeks 1–4 gpt-5.6-luna; ChatGPT's free default moved to GPT-6 Luna on Oct 8, so week 4 (Oct 11) was still measured with the older model. From week 5 (Oct 18) the weekly series uses gpt-6-luna; in week 5 the ChatGPT questions will also be run once more on gpt-5.6-luna as a same-day bridge, to estimate how much the model change may move the numbers. That bridge run will be reported separately and not mixed into the series. The new categories use gpt-6-luna from their first week. Gemini side: gemini-3.6-flash throughout, no change.
